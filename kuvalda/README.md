Kuvalda is a hashing tool.
It can id, crack and create hashes.

Usage
id: python3 kuvalda.py id <hash>
crack: python3 kuvalda.py crack <hash> -w <wordlist>
make: python3 kuvalda.py make <text-to-hash> - wrap in "" for spaced text
