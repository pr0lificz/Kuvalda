Kuvalda is a hashing tool. It can id, crack and create hashes.

## Usage

```bash
python3 kuvalda.py id <hash>
python3 kuvalda.py crack <hash> -w <wordlist>
python3 kuvalda.py make <text>        # wrap in "" for spaced text
python3 kuvalda.py credits            # show dev credits
python3 kuvalda.py help               # show info / usage
```

## Install

```bash
pip install -r requirements.txt
```
